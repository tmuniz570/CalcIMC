## 📌 Overview

**CalcIMC** is a native Android mobile application written in **Kotlin** that computes a user's **Body Mass Index (BMI / IMC)** from weight (kg) and height (m) inputs and provides immediate WHO health category feedback.

---

## ✨ Key Features

* **Real-Time BMI Computation**: Validates numeric input fields and calculates $\text{BMI} = \frac{\text{weight (kg)}}{\text{height (m)}^2}$.
* **Health Category Classification**: Categorizes results into *Underweight*, *Normal Weight*, *Overweight*, and *Obesity* tiers with clear visual indicators.
* **Clean Native Architecture**: Built with Kotlin, Android ViewBinding/XML layouts, and Gradle build automation.

---

## 🚀 Build & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/tmuniz570/CalcIMC.git
   ```
2. Open the project in **Android Studio** and run on an emulator or physical Android device (`Shift + F10`).
